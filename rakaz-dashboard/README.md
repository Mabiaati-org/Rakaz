# rakaz-dashboard — لوحة إدارة ركاز

Vite + React. تتصل بـ `rakaz-api` وتتطلب تسجيل دخول بحساب مدير.

## التشغيل

```bash
cp .env.example .env      # VITE_RAKAZ_API_URL = عنوان الـ API
npm install
npm run dev               # http://localhost:5173
```

يجب أن يكون عنوان اللوحة ضمن `CORS_ORIGINS` في إعدادات الـ API.

## الصفحات

| الصفحة | الوظيفة |
| --- | --- |
| نظرة عامة | مؤشرات اليوم + إرسال إشعار لأولياء الأمور أو السائقين |
| الرحلات الحية | بث مباشر (SSE) لرحلات اليوم وحالة كل طالب وموقع الباص |
| الطلاب | إضافة/تعديل الطلاب وإسنادهم للمسارات (ينشئ حساب ولي الأمر تلقائياً) |
| أولياء الأمور / السائقون | الحسابات وإعادة إصدار كلمة المرور المؤقتة |
| المسارات | إسناد السائق وترتيب المحطات وأوقاتها |
| المدارس، الغياب، المالية، الدعم، الإعدادات | إدارة بقية البيانات |

كلمة المرور المؤقتة تظهر **مرة واحدة** عند إنشاء الحساب أو إعادة التعيين؛ سلّمها لصاحبها مباشرة.

## البناء للنشر

```bash
VITE_RAKAZ_API_URL=https://api.example.com npm run build   # الناتج في dist/
```

`dist/` موقع ثابت (SPA): يجب أن يعيد السيرفر `index.html` لأي مسار غير موجود.
